How it works

From upload to evidence.

Media is validated before processing, passed to an explicitly configured model, and reported with its limitations. Temporary uploads are removed after the request.

Read about the technology
STEP 01

Validate safely

Check file type, signature and processing limits before decoding.

STEP 02

Run configured model

No detector is faked or silently substituted when configuration is absent.

STEP 03

Interpret carefully

See model scores and screening scope, not a definitive real-or-fake verdict.

Responsible use: automated detectors can be wrong and may perform unevenly across content. Do not use a result alone to make consequential decisions. Avoid uploading sensitive or private media.
