About the technology

Evidence, with boundaries.

TruthLens is an educational media-screening application designed to make model limitations visible.

Image model

Explicitly configured

The backend does not treat general image classification as AI-image detection. Model inference is disabled unless an image model and verified class labels are configured by the operator. When unavailable, the application says so rather than returning a fabricated result.

One reviewed educational candidate is Organika's SDXL detector. It distinguishes the configured artificial and human labels, but is not a universal detector. See the model card and project README for setup and licensing notes.

No face-manipulation detector is included.

Video workflow

Frame-based screening

Video analysis samples a limited number of frames and applies the configured image model independently. It does not examine temporal artifacts, audio, lip synchronization or motion coherence. Frame aggregation is disclosed in each report.

Important limitations

A detector is not a verdict.

Errors are possible

False positives and false negatives occur. Model performance varies with content, compression, editing and training distribution.

Scores need context

Scores are model outputs and should not be read as probabilities unless explicitly calibrated and documented.

Not for high-stakes decisions

Do not use this tool as the sole basis for legal, employment, safety or other consequential decisions.

Privacy: uploaded files are processed temporarily and removed after each request; history stores metadata only. For local development, avoid exposing this service to untrusted networks.
